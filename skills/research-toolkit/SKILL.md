# Research Toolkit

One entry point for 61 research, statistics, data-wrangling and machine-learning method guides. This file only routes; the real procedures, formulas, validity checks and reporting wording live in `references/`. Each reference is an unmodified copy of a standalone skill, so it already contains runnable code, worked numbers and its own "Validity conditions" section.

## How to work (and why)

1. **Pick the family, then the reference.** Match the user's task to the tables below. Many tasks need several references (a typical dataset analysis uses a `pda-` loader, an `srm-` summary and test, and an `srm-`/`pda-` plot). Open every one that plausibly applies.
2. **Read each chosen reference in full before coding.** Long code lines and the *Validity conditions* section carry the details that change results (expected-count rules, n >= 25 checks, standardising first). Truncating the file with `head`, `cut` or similar hides them, so use `view` (with line ranges for long files) instead.
3. **Run the check the reference prescribes before the test.** Confirm the method's assumptions on the user's data and say which hold. If one fails (for example expected counts below 5, skewed data, a circular outcome), switch to the alternative the reference names and tell the user why.
4. **Adapt, don't paste.** The reference examples use demo data (iris, digits, textbook tables). Keep the algorithm and conventions (seeds, `ddof=1`, headless matplotlib) but bind them to the user's columns, and print the numbers you report.
5. **Label provenance honestly.** In the final answer, mark each method or figure as "from reference X" or "my own addition" (for example a test, plot or model the references do not cover). Before crediting a reference with a technique, confirm it appears there, e.g. `grep -il clustermap references/*/*.md`.
6. **Report in the reference's wording.** The `srm-` references give the three-part conclusion (strength of evidence, test statistic and P, sample summary). Association is not causation; a small P is not a large effect.

## Environment notes

The references assume Python with numpy, pandas, scipy, statsmodels, scikit-learn, matplotlib and seaborn, run headless (`matplotlib.use("Agg")`). Several state that `pythonmeta`, `zepid`, `pyarrow`, `umap-learn`, `xgboost`, `lightgbm` and `tensorflow` are **not** installed and give stdlib/sklearn replacements. Follow those replacements rather than installing packages.
